# Superstore-Sales-Power-Bi-Dashboard
Power BI project containing four Superstore dashboards
Superstore Sales Analysis Dashboard

Project Overview

This project presents a sales analysis of Superstore data using Microsoft Power BI. It contains four interactive dashboards designed to analyze sales, profit, product categories, and business performance.

Tools Used

Microsoft Power BI

Power Query for data preparation

DAX for calculations and measures

Data visualization and interactive slicers

Dashboards

Dashboard 1: Sales Overview

Provides an overview of key sales and business performance metrics using cards, charts, and slicers.

Dashboard 2: Category and Segment Analysis

Analyzes sales performance across product categories, sub-categories, and customer segments.

Dashboard 3: Profit Analysis

Focuses on profit performance and comparisons across relevant business dimensions.

Dashboard 4:Customer and Order Analysis

Analyzes customer-related information and order details to understand customer segments, order patterns, shipping modes, and sales activity.

Key Features

Four Power BI dashboards

Interactive slicers and filters

KPI cards and charts

Sales and profit analysis

Business insights through data visualization

Project Files

Superstore Sales Power Bi DASHBOARD.pbix — Power BI report file

Dashboard screenshots — visual previews of the four dashboards

How to View the Project

Download the .pbix file and open it using Microsoft Power BI Desktop to explore the report.
